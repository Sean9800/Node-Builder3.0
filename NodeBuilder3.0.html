Campus Node Builder

1) Load a campus map image (screenshot of Google Maps satellite view works well). 2) In Add node mode, click a location, then name it. 3) Switch to Link nodes mode and click two nodes to connect them (click the same pair again to remove the link). 4) Switch to Calibrate GPS mode and click 3+ spots whose real-world latitude/longitude you know (e.g. look them up on Google Maps) - this teaches the tool how pixels map to real coordinates, so every node gets a lat/lng automatically.
